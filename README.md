# RAG-Agent-learning

这是我的 AI Agent 开发学习仓库。我在这里用小练习理解新的技术，再把适合的方案用到[非线性动力系统论文智能分析助手](https://github.com/jianjian27/nonlinear-dynamics-paper-assistant)中。长期目标是积累 AI Agent / LLM 应用开发实习需要的能力，并留下能在面试中讲清设计取舍、验证过程和实际结果的项目作品。

## 两个仓库怎么配合

| 仓库 | 用途 | 典型产出 |
| --- | --- | --- |
| `RAG-Agent-learning` | 在小场景里练习新概念和框架机制 | 可运行示例、测试、学习笔记 |
| `nonlinear-dynamics-paper-assistant` | 在真实论文任务中接入和验证方案 | 功能、回归用例、对比报告、Release Notes |

需要先理解状态恢复、权限边界或评估方法时，先在这里做最小实验。能复用现有业务代码、又能用离线测试验证的功能，可以直接在项目里边做边学。

## 当前项目进度

论文助手已经具备 PDF 结构解析、SQLite 知识库、本地 Embedding 与向量缓存、带原文证据的 RAG 问答，以及可在命令行和 Gradio 中使用的自研科研 Agent。Agent 能查看论文列表、读取章节结构、检索带页码的原文证据。

自研 Agent 已用 4 个真实调用案例跑通基线，覆盖论文列表、论文概览、原文检索和直接对话。当前通过率是这组冒烟案例的结果。更复杂的跨论文问题、引用正确性和检索排序需要各自的评估样例。

框架迁移已具备 LangChain 工具适配器和阿里云百炼模型工厂。下一步在主项目中用 `create_agent()` 组装 Agent，统一运行结果和调用轨迹，再与自研版本比较。这个阶段可以直接进入项目实践。

## 后续学习与开发路线

| 阶段 | 学习方式 | 论文助手中的验收目标 |
| --- | --- | --- |
| **1. LangChain Agent 与基线对照 · 当前** | **直接做项目。** 学习 `create_agent()`、消息对象、工具调用与结果适配 | 复用现有只读工具，离线验证一次完整的工具调用循环。用同一论文库和评估集比较两种 Agent，记录模型配置、通过情况、调用次数和耗时 |
| **2. LangGraph 有状态研究流程** | **先做最小练习。** 学习 State、节点、条件路由、checkpoint 与恢复 | 实现一个结构化多论文对比流程，先明确论文范围，再收集证据，最后生成对比结果。验证中断后恢复是否能复用已完成步骤。需要用户确认论文范围时，再加入人工确认 |
| **3. MCP 工具接入** | **先做最小练习。** 用本地只读工具理解客户端、服务端、工具发现和调用 | 将一个现有只读论文工具作为 MCP 工具接入，验证客户端能发现并调用它，检查非法参数和异常响应。保留现有业务实现 |
| **4. 服务化与交付** | **先做最小练习，再接项目。** 练习 FastAPI 请求与响应、Docker 镜像与数据挂载、基础 CI | 为一个稳定的 Agent 入口提供 API，验证错误响应、环境变量配置和数据库挂载。在干净环境完成启动和冒烟测试，CI 运行离线测试 |
| **5. RAG 质量优化** | **从项目失败案例出发。** 复用第 2 章指标，按需要补学关键词检索、混合检索、重排或 PDF 解析 | 先标注一小组问题对应的证据，再定位问题出在解析、切分、召回、排序还是生成。每次只改一项，比较证据命中、引用正确性与耗时 |

运行追踪、错误分类和回归用例随各阶段一起积累。OCR、表格和公式提取等能力，根据评估中出现的真实缺口安排。Agent Skills 可以在出现需要复用的研究流程后独立练习，重点比较它如何封装操作说明与资源，以及它和 MCP 工具接口各自负责什么。

## 每个练习怎么记录

1. **为什么需要**　记录一个真实需求、失败案例或重复工作。
2. **放在哪一层**　指出它属于工具、模型、工作流、检索、评估还是服务接口。
3. **数据怎样流动**　写一个具体输入，说明经过哪些组件、最后返回什么。
4. **如何测试**　优先提供本地可重复的用例，真实模型调用用于验收关键路径。
5. **如何判断是否改善项目**　记录改动前后的结果，说明比较条件和观察到的取舍。

一个阶段完成后，在论文助手的 Release Notes 中记录实现的功能、用到的技能、验证结果和当前限制。对外展示优先选能复现的样例，例如同一问题在两个 Agent 中的工具轨迹对比，或一次可恢复的多论文研究流程。

## 开始学习

在本仓库根目录安装现有练习依赖，然后按章节运行示例。

```powershell
python -m pip install -r requirements.txt
python "第1章 Tool Calling基础/1.1 JSON与JSON Schema.py"
```

继续当前阶段时，从论文助手中的 LangChain Agent 组装和离线工具调用测试开始。完成同一评估集下的对比后，再在本仓库开设 LangGraph 状态与恢复的前置练习。
